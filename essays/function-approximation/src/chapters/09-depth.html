Chapter 9

Depth: folding a curve instead of adding bricks

Chapter 8 added neurons side by side. A network can also stack layers, so that each layer feeds the next. Does that buy anything that simply adding more neurons does not?

Take a tent: a function that rises from 0 to 1 and falls back to 0. Two ReLU neurons make one. Feed a tent into another tent and the curve folds: its two slopes become four. Fold again and you get eight. Each layer doubles the number of linear pieces, using the same two neurons.

The counting is simple. The deep net uses about 6 parameters per layer, so {{fold_params8}} in total for 8 layers, and draws {{fold_pieces8}} linear pieces. A single layer with the same budget affords {{shallow_w8}} neurons, and a one-layer net with W neurons cannot have more than W+1 pieces. Depth grows the number of pieces exponentially; width grows it linearly.

Two cautions keep this honest. First, the sawtooth is a special function, chosen because folding makes it cheap. Depth is no free lunch for every curve. Second, these weights were written down by hand. Gradient descent is not guaranteed to find them, and the next chapter shows how training can be slow even when a good network exists. This is the third of the errors from chapter 5, optimisation: the family can contain a good answer that training never reaches.

Math (skippable)

On \([0,1]\), \(\operatorname{tent}(u)=2\,\mathrm{relu}(u)-4\,\mathrm{relu}(u-\tfrac12)\). The \(L\)-fold composition has \(2^L\) linear pieces, each of slope \(\pm 2^L\). A one-hidden-layer ReLU net with \(W\) units is piecewise linear with at most \(W+1\) pieces.

Telgarsky (2016) makes this precise: some functions computed by deep nets of modest size need exponentially many units if the net is forced to be shallow.
